1. Grid Fundamentals: Containers and Tracks

CSS Grid is a two-dimensional layout system: it controls rows and columns simultaneously. Declare display: grid on a container and its direct children become grid items, placed automatically into rows and columns you define with grid-template-columns and grid-template-rows.

Tracks are the rows and columns themselves; the lines between them are grid lines; the space between tracks is the gutter, controlled by gap. Unlike flexbox, which lays out along one axis, grid lets you describe the entire skeleton of a page in a few declarations.

.gallery {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr; /* three equal columns */
  grid-template-rows: auto auto;      /* two rows sized to content */
  gap: 16px;                          /* gutters */
}

2. Sizing Like a Pro: fr, repeat(), minmax()

The fr unit distributes free space proportionally: 1fr 2fr 1fr gives the middle column twice the leftover space of the others. It is the single most useful grid concept — forget percentage math.

repeat() removes repetition: repeat(4, 1fr) equals four equal columns. minmax(min, max) sets flexible bounds, and combined with auto-fit or auto-fill it creates grids that adapt to any viewport without a single media query.

.cards {
  display: grid;
  /* as many 240px+ columns as fit, stretching to fill */
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 20px;
}

3. Placing Items Exactly Where You Want

By default items flow row by row, but you can take control. grid-column: 1 / 3 spans an item from line 1 to line 3. Negative indices count from the end: grid-column: 1 / -1 spans the full width — perfect for headers and footers.

grid-template-areas lets you draw the layout as ASCII art, then assign items with grid-area. It is the most readable way to express page skeletons, and redefining areas per breakpoint makes responsive redesigns trivial.

.page {
  display: grid;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  grid-template-columns: 220px 1fr;
}
.page > header { grid-area: header; }
.page > aside  { grid-area: sidebar; }
.page > main   { grid-area: main; }
.page > footer { grid-area: footer; }

4. Real-World Layout Patterns

The classic 'holy grail' layout — header, footer, sidebar, content — is a dozen lines with areas. Card grids use the auto-fit pattern from section 2. Dashboards combine fixed sidebars (240px) with fluid content (1fr) and use grid-auto-rows: minmax(120px, auto) so widgets never collapse.

For magazine-style layouts, let featured items span multiple tracks: .featured { grid-column: span 2; grid-row: span 2; }. Dense packing with grid-auto-flow: dense fills holes left by spanning items — great for galleries, though it can reorder visual vs. DOM order, so use it carefully for accessibility.

5. Responsive Grids Without Media Queries

Intrinsic responsive design is grid's superpower. auto-fit + minmax() collapses columns as the viewport shrinks — no breakpoints needed for the common cases. When you do need breakpoints, redefine grid-template-areas or column counts at each step.

Watch out for two gotchas: grid items default to min-width: auto, which can prevent shrinking — set min-width: 0 on items containing long content. And remember gap is not a margin: it never collapses and never applies at container edges.

6. Frequently Asked Questions (FAQs)

When should I use Grid instead of Flexbox?

Use Grid for two-dimensional layouts (rows and columns together: page skeletons, card grids). Use Flexbox for one-dimensional layouts (a nav row, a button group). They compose well together.

What does 1fr actually mean?

One fraction of the free space left after fixed-size tracks are laid out. 1fr 2fr splits leftovers into thirds, giving the second track twice as much.

How do I center something in Grid?

Use place-items: center on the container to center items on both axes, or place-self: center on a single item.

Why won't my grid item shrink?

Grid items default to min-width: auto, which respects content size. Set min-width: 0 (or overflow: hidden) to allow shrinking.

Is CSS Grid supported in all modern browsers?

Yes — Grid has been supported in all evergreen browsers since 2017. No prefixes or fallbacks are needed in 2026.
