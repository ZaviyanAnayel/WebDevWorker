1. Holy Grail & App Shells

The holy grail — header, footer, nav sidebar, and fluid content — tormented developers for a decade of float hacks. With grid areas it's declarative: name the regions, assign the elements, done. Responsive variants just redefine the areas.

App shells extend the pattern: fixed-width icon rail, collapsible sidebar, main content, and optional right panel. Use grid-template-columns: auto 240px 1fr 320px with areas, collapsing panels via a class that redefines the template.

.holy-grail {
  display: grid;
  min-height: 100vh;
  grid-template-columns: 220px 1fr;
  grid-template-areas:
    "header header"
    "nav main"
    "footer footer";
}
@media (max-width: 720px) {
  .holy-grail {
    grid-template-columns: 1fr;
    grid-template-areas: "header" "main" "nav" "footer";
  }
}

2. Card Grids That Adapt

The intrinsic card grid — repeat(auto-fit, minmax(260px, 1fr)) — is the most-used layout on the modern web for good reason: it needs no breakpoints and never leaves orphan columns. Pair with grid-auto-rows: 1fr for equal-height rows.

Inside each card, use flexbox column with margin-top: auto on the footer to pin actions to the bottom regardless of content length. This two-line trick solves the ragged-card problem elegantly.

3. Split Screens & Asymmetry

Split screens (50/50 or 40/60) are grid-template-columns: 1fr 1fr with full-bleed media on one side. Asymmetric editorial layouts use ratios like 2fr 1fr or overlapping grid placement where text spans columns over an image.

Overlap is grid's secret weapon: place two items in the same grid area with different alignments, and use z-index for layering. Magazine-style pull quotes overlapping hero images need no absolute positioning hacks.

4. Sticky Sidebars and Headers

Sticky sidebars (position: sticky; top: 1rem; align-self: start) keep TOCs and filters visible while content scrolls — but the sidebar must be shorter than its container, and no ancestor can have overflow: hidden.

Sticky table headers and section navs follow the same rules. For headers that hide on scroll-down and reveal on scroll-up, a tiny IntersectionObserver toggling a transform class beats scroll listeners for performance.

5. Heroes, Centering, and Finishing Touches

The centered hero is display: grid; place-items: center; min-height: 80vh — one line for perfect centering that flexbox needs three for. Full-bleed sections inside constrained containers use the width: 100vw; margin-left: calc(50% - 50vw) trick (mind the scrollbar).

Finish with consistent spacing: a fluid --space scale via clamp(), section padding that breathes (clamp(48px, 8vw, 120px)), and a max-width container (min(1200px, 100% - 2rem)) that centers with safe gutters everywhere.

/* The only centering snippet you'll ever need */
.hero {
  display: grid;
  place-items: center;
  min-height: 80vh;
  text-align: center;
  padding: clamp(48px, 8vw, 120px) 1rem;
}

6. Frequently Asked Questions (FAQs)

What is the holy grail layout?

A classic page structure with header, footer, fixed sidebar, and fluid main content. CSS Grid areas implement it in a few declarative lines.

How do I make cards equal height?

In a grid, rows are equal height by default. Inside cards, use flexbox column with margin-top: auto on the footer to align actions.

How do I center a div in 2026?

display: grid; place-items: center on the parent — the shortest reliable centering in CSS.

What is a full-bleed section?

A section that breaks out of a constrained container to span the full viewport width, typically via 100vw with negative margins.

Should layouts use Grid or Flexbox?

Grid for the page/section skeleton (two-dimensional), flexbox inside components (one-dimensional). They nest beautifully.
