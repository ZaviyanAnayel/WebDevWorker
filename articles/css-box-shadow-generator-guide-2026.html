6. Frequently Asked Questions (FAQs)

What is the difference between blur radius and spread radius in CSS?

Blur radius determines the softness and feathering of the shadow edge (higher values create a wider, hazier gradient). Spread radius physically expands or shrinks the size of the shadow mask before blur is applied; a positive spread makes the shadow larger than the element, while a negative spread shrinks it.

Why do single-layer box shadows look cheap or unnatural?

In the real world, light does not emanate from a single point source without ambient reflections. Photons bounce off surrounding surfaces, creating soft ambient light and sharp contact shadows. Layering multiple shadows simulates these physical light bounces.

Can box-shadow cause browser repaint performance drops?

Heavy box-shadows with large blur radii (e.g. blur > 50px) on frequently animated elements can trigger CPU paint cycles. To optimize performance, apply transform: translateZ(0) or will-change: transform to promote the element to a separate GPU compositor layer, or animate opacity on a pseudo-element rather than animating the box-shadow property directly.

How does inset box-shadow differ from regular box-shadow?

Regular box-shadow renders outside the element perimeter and is clipped inside. Inset box-shadow flips this behavior, drawing the shadow inside the container frame to create sunken, recessed, or pressed UI button states.

Does box-shadow affect the DOM layout box or trigger reflows?

No. The box-shadow property does not occupy document layout space, meaning it does not alter sibling element coordinates or trigger expensive DOM reflow (layout recalculation).
