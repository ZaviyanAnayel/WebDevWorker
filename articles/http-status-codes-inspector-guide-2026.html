6. Frequently Asked Questions (FAQs)

What is the difference between a 301 and a 302 redirect for SEO?

A 301 Moved Permanently instructs search engines that the page has permanently relocated, transferring link authority (PageRank) to the new URL. A 302 Found indicates a temporary relocation, telling crawlers to keep indexing the original URL.

What is the difference between 401 Unauthorized and 403 Forbidden?

401 Unauthorized means authentication is required (the user has not logged in or provided a valid token). 403 Forbidden means the identity is known, but that user lacks permission to access the requested resource.

What is a "Soft 404" and why is it penalized by Google?

A Soft 404 occurs when a server returns a missing page error message in the visual HTML but serves it with an HTTP 200 OK status code. Google crawlers waste crawl budget indexing non-existent pages, resulting in search ranking penalties.

What does a 502 Bad Gateway error mean?

A 502 Bad Gateway means a reverse proxy server (such as Nginx, Cloudflare, or AWS ALB) received an invalid response or connection drop from the upstream backend application server (such as Node.js, PHP-FPM, or Python Gunicorn).

When should a REST API return 201 Created instead of 200 OK?

201 Created should be returned whenever an HTTP POST request results in the successful creation of a new database entity, ideally accompanied by a Location header pointing to the new resource.
