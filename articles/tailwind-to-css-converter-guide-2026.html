6. Frequently Asked Questions (FAQs)

Why convert Tailwind classes to vanilla CSS?

Many platforms—such as HTML email rendering engines (Outlook, Gmail), Web Components, and legacy CMS environments—do not support build-time Tailwind compilation. Converting to pure CSS provides universal compatibility.

Does this converter support fractional Tailwind spacing?

Yes. Fractional and numeric scales like p-2, p-4, px-6, and gap-8 are mathematically computed using the official 0.25rem scale factor.

Can I use the output directly in React JSX style props?

Yes. The inline style string can be copied directly into HTML style attributes or converted into React camelCase objects.

How are color palettes handled?

Standard Tailwind default palettes (slate, zinc, blue, emerald, amber, red) are translated into their exact hex equivalents.

Does this tool work offline?

Yes. As with all WebDevWorker utilities, all translation algorithms run locally within your browser memory.

Are responsive prefixes (md:, lg:) supported?

Responsive variants require separate @media queries, while this tool focuses on core component styles and inline properties.
