2. How It Works: Syntax, Format & Specification

AI Code Doctor accepts source code in plain text, wrapped in a <pre><code> block or pasted directly into the input field. It detects the language automatically by analyzing file extensions, shebang lines, or common syntax tokens. Supported languages include JavaScript/TypeScript, Python, Java, C#, Ruby, Go, and PHP. The underlying model follows the ECMAScript specification for JS, PEP 8 for Python, and equivalent standards for other languages.

When you submit code, the AI parses it into an abstract syntax tree (AST), then runs a series of rule‑based checks (e.g., undefined variables, type mismatches, unreachable code). After the AST analysis, the language model generates natural‑language explanations and concrete <pre><code> patches. The output respects original formatting, preserving indentation, line endings, and comments.

Formatting guidelines for optimal results:

  • Use consistent indentation (2‑space for JS/TS, 4‑space for Python).
  • Include a minimal reproducible example; remove unrelated boilerplate.
  • Avoid inline minified code; expand it for better tokenization.
  • Provide any relevant import statements so the AI can resolve symbols.

Because the tool runs locally, it leverages the browser’s WebAssembly runtime to execute the model efficiently. No network calls are made, ensuring that even air‑gapped environments can benefit from AI‑powered debugging.
