1. Setup and the Coordinate System

The <canvas> element is a blank bitmap; the 2D rendering context (getContext("2d")) is your brush. Coordinates start at the top-left corner (0,0), x grows rightward, y grows downward — the opposite of math-class convention, which trips up every beginner exactly once. Everything you draw is immediate-mode: once a shape is painted, the canvas forgets it, so animation means clearing and redrawing every frame.

<canvas id="stage" width="800" height="450"></canvas>
<script>
  const canvas = document.getElementById("stage");
  const ctx = canvas.getContext("2d");

  // Crisp rendering on Retina/HiDPI displays
  function setupHiDPI(canvas, ctx) {
    const dpr = window.devicePixelRatio || 1;
    const { width, height } = canvas.getBoundingClientRect();
    canvas.width = width * dpr;
    canvas.height = height * dpr;
    ctx.scale(dpr, dpr); // draw in CSS pixels from here on
    return { width, height };
  }
  const { width: W, height: H } = setupHiDPI(canvas, ctx);

  ctx.fillStyle = "#0f172a";
  ctx.fillRect(0, 0, W, H); // paint the background
</script>

HiDPI handling is not optional polish — without scaling by devicePixelRatio, canvas graphics look blurry on every modern phone and laptop. The pattern above sizes the backing store in device pixels while keeping your drawing code in CSS pixels. Re-run setup on window resize so the canvas stays sharp at any viewport.

2. Shapes, Paths and Styles

Rectangles are one-liners (fillRect, strokeRect, clearRect), but everything interesting goes through paths: beginPath() starts one, then you add sub-paths with moveTo, lineTo, arc, and Bézier curves, finishing with fill() or stroke(). Forgetting beginPath() is the classic bug — without it, new shapes join the previous path and inherit its styling.

// Rectangles, circles, and a custom path
ctx.fillStyle = "#eab308";
ctx.fillRect(40, 40, 120, 80);            // filled rectangle

ctx.strokeStyle = "#38bdf8";
ctx.lineWidth = 6;
ctx.strokeRect(200, 40, 120, 80);         // outlined rectangle

ctx.beginPath();                          // start a fresh path!
ctx.arc(400, 80, 50, 0, Math.PI * 2);    // full circle
ctx.fillStyle = "#10b981";
ctx.fill();

// A speech-bubble-ish polygon with rounded joins
ctx.beginPath();
ctx.moveTo(500, 40);
ctx.lineTo(620, 40);
ctx.lineTo(620, 100);
ctx.lineTo(560, 100);
ctx.lineTo(540, 125);
ctx.lineTo(530, 100);
ctx.lineTo(500, 100);
ctx.closePath();
ctx.fillStyle = "#f472b6";
ctx.fill();
ctx.lineJoin = "round";
ctx.strokeStyle = "#9d174d";
ctx.lineWidth = 4;
ctx.stroke();

Styling controls live on the context: fillStyle/strokeStyle accept any CSS color, gradient, or pattern; lineWidth, lineCap (butt/round/square), and lineJoin shape strokes; globalAlpha and globalCompositeOperation control transparency and blending. Save and restore context state with ctx.save()/ctx.restore() around transforms so one shape's rotation never leaks into the next.

3. Gradients, Images and Text

Gradients elevate flat shapes instantly. createLinearGradient(x0,y0,x1,y1) blends along a line; createRadialGradient radiates from a circle — add color stops with addColorStop(offset, color) and assign the gradient to fillStyle. Images draw with drawImage() in three flavors: whole image, scaled, or cropped from a source rectangle (the basis of sprite-sheet animation).

// Linear gradient sky + radial glow
const sky = ctx.createLinearGradient(0, 0, 0, H);
sky.addColorStop(0, "#0c4a6e");
sky.addColorStop(1, "#082f49");
ctx.fillStyle = sky;
ctx.fillRect(0, 0, W, H);

const glow = ctx.createRadialGradient(400, 200, 10, 400, 200, 120);
glow.addColorStop(0, "rgba(234,179,8,0.9)");
glow.addColorStop(1, "rgba(234,179,8,0)");
ctx.fillStyle = glow;
ctx.fillRect(0, 0, W, H);

// Draw an image (wait for load!) with cover-style cropping
const img = new Image();
img.src = "/assets/hero.png";
img.onload = () => {
  ctx.drawImage(img, 0, 0, W, H); // stretched; compute crop for cover fit
};

// Crisp text with alignment control
ctx.font = "700 42px system-ui, sans-serif";
ctx.textAlign = "center";
ctx.textBaseline = "middle";
ctx.fillStyle = "#f8fafc";
ctx.fillText("Hello, Canvas!", W / 2, 60);

Two image gotchas: always draw inside onload (drawing before load silently paints nothing), and respect CORS — drawing a cross-origin image without crossOrigin="anonymous" taints the canvas, permanently blocking toDataURL() and pixel reads. For text, set font with the full CSS shorthand each time; canvas has no inherited styles.

4. The Animation Loop: requestAnimationFrame

requestAnimationFrame (rAF) is the heartbeat of canvas animation: the browser calls your function before each repaint, typically 60 times per second, and pauses automatically when the tab is hidden. The loop pattern is always the same — update state, clear, draw, request the next frame. Crucially, drive motion with delta time (seconds since the last frame) so animation speed stays constant on 60Hz, 120Hz, and throttled displays alike.

const ball = { x: 100, y: 100, vx: 260, vy: 180, r: 24 };
let last = performance.now();

function loop(now) {
  const dt = Math.min((now - last) / 1000, 0.05); // seconds, clamped
  last = now;

  // 1. update physics with delta time
  ball.x += ball.vx * dt;
  ball.y += ball.vy * dt;
  if (ball.x < ball.r || ball.x > W - ball.r) ball.vx *= -1;
  if (ball.y < ball.r || ball.y > H - ball.r) ball.vy *= -1;

  // 2. clear and redraw
  ctx.clearRect(0, 0, W, H);
  ctx.fillStyle = "#0f172a";
  ctx.fillRect(0, 0, W, H);

  const g = ctx.createRadialGradient(
    ball.x - 8, ball.y - 8, 4, ball.x, ball.y, ball.r);
  g.addColorStop(0, "#fde68a");
  g.addColorStop(1, "#d97706");
  ctx.fillStyle = g;
  ctx.beginPath();
  ctx.arc(ball.x, ball.y, ball.r, 0, Math.PI * 2);
  ctx.fill();

  // 3. schedule next frame
  requestAnimationFrame(loop);
}
requestAnimationFrame(loop);

Clamping delta time (here to 50ms) prevents physics explosions after tab-switch pauses. For games, separate your fixed-timestep simulation from rendering; for visualizations, easing functions (easeInOutCubic and friends) turn linear interpolation into natural motion. Never use setInterval for animation — it desyncs from repaints and keeps running in background tabs, wasting battery.

5. Performance and HiDPI Best Practices

Canvas is fast until it is not. The biggest wins: batch draws by style (changing fillStyle is expensive — group same-colored shapes), avoid shadowBlur in hot loops (it is one of the slowest canvas operations), and pre-render static layers to offscreen canvases once, then drawImage them each frame instead of redrawing hundreds of shapes.

// Pre-render a static starfield once, blit it every frame
const bg = document.createElement("canvas");
bg.width = W; bg.height = H;
const bctx = bg.getContext("2d");
for (let i = 0; i < 300; i++) {
  bctx.fillStyle = `rgba(255,255,255,${Math.random() * 0.8})`;
  bctx.fillRect(Math.random() * W, Math.random() * H, 2, 2);
}
// in the loop: ctx.drawImage(bg, 0, 0);  // one cheap blit

// Only redraw regions that changed (dirty rectangles)

6. Frequently Asked Questions (FAQs)

What is the difference between Canvas and SVG?

Canvas is an immediate-mode bitmap API: you paint pixels and the browser forgets the shapes, making it ideal for games and thousands of objects. SVG is retained-mode: every shape is a DOM node, better for accessible, styleable, interactive graphics.

Why does my canvas look blurry on some screens?

The canvas backing store defaults to CSS-pixel resolution. Multiply width and height by window.devicePixelRatio and ctx.scale() by the same factor so drawing stays sharp on Retina and HiDPI displays.

Should I use setInterval or requestAnimationFrame for animation?

Always requestAnimationFrame. It syncs with the display's refresh rate, pauses in background tabs to save battery, and avoids the tearing and drift that setInterval causes. Drive motion with delta time for consistent speed.

How do I make canvas content accessible?

Canvas pixels are invisible to screen readers, so provide fallback content inside the canvas element, mirror key state in ARIA live regions, ensure keyboard equivalents for interactions, and consider SVG for content that must be natively accessible.

What is canvas tainting and how do I avoid it?

Drawing a cross-origin image without CORS approval taints the canvas, permanently blocking toDataURL() and getImageData(). Set img.crossOrigin = 'anonymous' and serve the image with CORS headers, or host images on the same origin.
